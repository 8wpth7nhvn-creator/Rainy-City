# Rain Animation

## Over het project

Dit project is een interactieve animatie gemaakt met JavaScript en p5.js.

In de animatie valt regen op de grond. De gebruiker kan de snelheid van de regen en de wind aanpassen. Ook is er bliksem aanwezig om de animatie dynamischer te maken.

## Gebruikte technologieën

* HTML
* CSS
* JavaScript
* p5.js

## Functionaliteiten

* Regen die naar beneden valt
* Instelbare regensnelheid
* Instelbare windsnelheid
* Bliksem
* Bewegende elementen
* Interactieve animatie

## Bestanden

* `index.html` – De HTML-structuur van de webpagina.
* `style.css` – De styling van de pagina.
* `sketch.js` – De JavaScript- en p5.js-code voor de animatie.

## Hoe werkt het?

De animatie wordt gemaakt met p5.js. In de `setup()` functie wordt het canvas aangemaakt en worden de beginwaarden ingesteld.

De `draw()` functie wordt steeds opnieuw uitgevoerd. Hierdoor kunnen de regendruppels, wind en andere elementen continu bewegen.

De snelheid van de regen wordt bepaald door een variabele in `sketch.js`. Door deze waarde aan te passen kan de regen sneller of langzamer vallen.

## Uitvoeren

Open `index.html` in een webbrowser om de animatie te bekijken.

Voor de beste ervaring kan het project worden geopend met Live Server in Visual Studio Code.
